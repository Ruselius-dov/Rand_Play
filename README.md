# Rand_Play

Rand_Play is a landing page for a random browser game picker. The user presses the Spin button, and a roulette-style reel chooses a game that launches in the browser without registration.

## Technologies

- HTML5
- Tailwind CSS (CDN)
- JavaScript: js/menu.js, js/roulette.js, js/stage.js, auth.js, i18n.js, validation.js, reset.js
- Embedded services: YouTube, Google Maps, Discord Widget
- Validation: RegEx

## Running locally

1. Clone the repository: git clone https://github.com/Ruselius-dov/Rand_Play.git
2. Open index.html in a browser or run Live Server in VS Code.
